Crear un Clúster en GKE

gcloud container clusters create olympics-cluster \
  --zone us-central1-a \
  --num-nodes 3 \
  --enable-autoscaling \
  --min-nodes 1 \
  --max-nodes 10 \
  --enable-ip-alias \
  --machine-type e2-standard-4 \
  --disk-size 25GB \
  --disk-type pd-standard \
  --tags allin,allout \
  --no-enable-network-policy



Autenticarse en el Clúster

gcloud container clusters get-credentials olympics-cluster --zone us-central1-a



Crear un Namespace para la Aplicación

kubectl create namespace olympics

kubectl get namespace

Para aplicar estas configuraciones en Kubernetes, puedes ejecutar los comandos

kubectl apply -f go-deployment.yaml
kubectl apply -f go-service.yaml
kubectl apply -f rust-deployment.yaml
kubectl apply -f rust-service.yaml
kubectl apply -f ingress.yaml




Configurar el Autoscaler Horizontal -> se hace despuesde crear los deployments

kubectl autoscale deployment [DEPLOYMENT_NAME] \
    --cpu-percent=70 \
    --min=3 \
    --max=10 -n olympics

Lo configuraremos más adelante cuando los deployments estén en su lugar, pero aquí está el comando 
básico que utilizarás cuando llegue el momento.
Este comando escalará un deployment entre 3 y 10 pods si el uso de CPU promedio en los pods excede el 70%.
